One job title, 60 characters at most, the weirdest one we could think of — a blind judge compares titles two at a time and picks the weirder, funnier one. Our title: **"Professional Mourner for Strangers' Funerals"**. Hired mourners are a real profession in many cultures; the twist is that the grieving is for strangers. It reads instantly, pictures a person doing it, and lands its joke on the first read.

## Run it

```sh
node main.ts
```

The program writes the title to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), exactly 44 characters, no trailing newline, and verifies the bytes on disk before exiting 0. It is deterministic by design: every run writes the same bytes. Node 22 or later, standard library only, no network, no secrets.
